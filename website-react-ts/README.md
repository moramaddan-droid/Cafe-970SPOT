# 970SPOT+ Cafe Mansoura - Responsive Website (React + TypeScript + Vite)

الموقع الرسمي التفاعلي لكافيه **970SPOT+ Cafe** في مدينة المنصورة، مصر.

## المميزات الفنية:
1. **تصميم عربي أصيل ومتجاوب (RTL):** متوافق 100% مع شاشات الجوال، الأجهزة اللوحية (Tablets)، وشاشات الحواسيب المكتبية (Desktop).
2. **منيو تفاعلي:** تصنيف الأقسام (قهوة ساخنة، مثلجة، ماتشا، بيكري ومخبوزات، منعشات)، مع بحث حي فوري (Live Instant Search).
3. **طلب واستفسار عبر واتساب:** نافذة استفسار مخصصة ترسل تفاصيل المشروب والملاحظات مباشرة إلى واتساب أو إنستغرام الكافيه.
4. **خرائط Google والاتجاهات:** موقع الكافيه في المنصورة (شارع فؤاد / المشاية) مع زر الاتجاهات المباشرة.
5. **روابط التواصل الاجتماعي:** إنستغرام الرسمي (@plus970spot.eg)، فيسبوك، تيك توك، وواتساب.
6. **معرض صور عالي الدقة:** استعراض لأجواء الكافيه وبار القهوة المختصة والماتشا.

## كيفية التشغيل محلياً:
```bash
cd website-react-ts
npm install
npm run dev
```

## كيفية بناء المشروع للنشر (Build for Production):
```bash
npm run build
```
ينتج مجلد `dist` الجاهز للرفع على Vercel، Netlify، Cloudflare Pages، أو أي استضافة ويب.
